# JUCE Starter vs AGPLv3 — VoiceMorph route review

Review date: 2026-11-21
Scope: VoiceMorph's public GitHub repository, intended free Windows x64 VST3/Standalone distribution, and current JUCE 8.0.6 build pin.

This is a project-fit review of published terms, not a legal opinion or a license election. The owner has asked to keep the repository public and prefers a $0 route. Do not treat a public repository as a selected open-source license.

## Use-case facts from the repository

- CMake fetches JUCE 8.0.6 and builds VST3 and Standalone formats.
- README describes a Windows x64 installer released through GitHub Releases.
- VoiceMorph's original source currently has no project-wide license. The repository contains JUCE notices saying JUCE is dual-licensed under AGPLv3 or a JUCE commercial EULA.
- Signalsmith Stretch is MIT; WORLD is optional modified BSD; current notices say neither Rubber Band nor research candidates are linked by default.
- Intended product price/distribution is understood to be free for now; project-owner revenue/funding and the number/status of human developers who contribute have not been established.

## Comparison

| Question | JUCE Starter (EULA route) | JUCE under AGPLv3 route |
|---|---|---|
| Framework cost | Free and perpetual under the current JUCE 8 EULA; capped at $20,000 annual revenue/funding. | No JUCE fee or revenue cap under AGPLv3; the project must comply with AGPLv3. |
| Fits distributing a free VST3? | The EULA grants the owner permission to distribute products, provided its terms and licence-seat requirements are met. | Yes, if the distributed covered work and source-delivery obligations comply. |
| Source visibility | The repository can remain publicly readable, but Starter does not by itself grant downstream users rights to reuse VoiceMorph source. A public repository without an explicit project license is not an open-source license. | VoiceMorph source must be explicitly licensed under AGPLv3 if it is the covered combined work. Source users receive rights under AGPLv3. |
| Binary releases | Keep the applicable JUCE licence in force while distributing binaries; follow the EULA and preserve notices. | Each binary release must provide the complete Corresponding Source for the AGPL-covered work under the AGPL delivery terms. GitHub can host source, but the exact source matching each binary and clear links must be maintained. |
| Developer/revenue conditions | Determine the license owner and covered Framework Users. EULA requires a license for each Framework User contributing to or modifying copyrightable work dependent on JUCE. The $20,000 limit is based on the previous 12 months: for an individual it covers all revenue/funding generated by that individual from all sources; for an entity it covers the entity and affiliates, from all sources. | No JUCE revenue cap or paid JUCE seats, but every relevant contributor must have authority to license their contributions under AGPLv3. |
| Compatibility with current source state | Public visibility can be kept, but do not add an AGPL license to the combined product while relying on JUCE's commercial EULA; JUCE 8 EULA restriction 2.3 limits open-source licensing that requires the Framework or combined software to be source-disclosed, derivative-work licensed, or freely redistributable. | Fits an explicitly source-open project more naturally. Update project-wide license, notices, build/source packaging and UI notices before binaries are distributed under this route. |

## Findings against VoiceMorph's intended use

### Starter

Starter is the simplest $0 route if the license owner is below the applicable $20,000 limit and all required Framework User seats are covered. The fact that the plug-in itself is free does not alone prove eligibility: the EULA defines the cap using the license owner's wider revenue/funding scope. If eligible, JUCE Starter can cover distributing a free binary, but the repository should state clearly that public source availability does not grant reuse rights unless the owner separately chooses a compatible source license. Do not apply AGPL to the same combined VoiceMorph/JUCE product under this route.

### AGPLv3

AGPLv3 better matches an intention to let users reuse and redistribute the public source, and avoids JUCE's revenue cap and paid JUCE seats. It requires a real license decision: VoiceMorph's original code must be licensed, all included/contributed code must have compatible rights, the AGPLv3 text and notices must ship, and every VST3 binary must be accompanied by its Corresponding Source and clear access. As JUCE is fetched at build time, the project must make the exact JUCE 8.0.6 source and any build scripts/patches needed for the binary available with the corresponding source. The plug-in UI should also provide the legal notices required for an interactive user interface.

Existing notices identify Signalsmith Stretch as MIT and WORLD as modified BSD, which are generally compatible with an AGPL project when their own notices/conditions are preserved. Recheck actual enabled dependencies and the exact pinned files when preparing a release.

## Provisional outcome

- If “public repository” means source is visible but downstream reuse is not required: prefer Starter, conditional on verifying the owner and seats meet the EULA requirements.
- If “public repository” means users should be permitted to fork, modify, and redistribute VoiceMorph: AGPLv3 is the closer fit, conditional on adopting it for the covered project and maintaining corresponding-source delivery for all binaries.
- These are alternatives for the same distribution route, not two licenses to combine for the same JUCE-based product.
- Until owner eligibility or AGPL intent is documented and the distribution materials are updated, the route remains unresolved; do not treat this review as approval for a formal GA or binary release.
